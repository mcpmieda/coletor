COLETOR DE FREQUÊNCIA 0.4 — INSTALADOR PARA WINDOWS

Este instalador de candidato operacional é exclusivo para validação interna.
O software só enviará dados após autorização real do computador no Ecossistema,
login no Smecel e aprovação da implantação do backend correspondente.

INSTALAR
1. Abra ColetorFrequencia-0.4.0-windows-x64-setup-candidato.exe.
2. Escolha a pasta e, se desejar, marque o atalho na área de trabalho.
3. Use Coletor de Frequência no menu Iniciar para abrir o programa.
4. Não é necessário instalar Python nem possuir permissões de administrador.
5. O computador precisa de Windows 10/11 x64, Edge, WebView2 e .NET 4.8.

DURANTE O USO
- O programa não é iniciado automaticamente com o Windows.
- Conexão, autorização e sessão do Smecel são operações explícitas.
- Sessão e fila podem ser protegidas por DPAPI mediante confirmação nativa.
- A agenda e as pausas compartilhadas dependem do servidor da escola.
- A janela abre no centro da área útil do monitor principal.

DESINSTALAR COM SEGURANÇA
1. Antes de remover, abra o menu Iniciar > Coletor de Frequência >
   Retirar acesso deste PC e confirme a operação.
2. Verifique se a revogação remota foi confirmada. Se houver código de
   pendência, peça ajuda e conclua a revogação no Ecossistema.
3. Verifique e reconcilie os lotes pendentes antes de retirar o aplicativo.
4. Desinstale por Configurações > Aplicativos > Coletor de Frequência.

A desinstalação remove os binários e atalhos do Coletor. Por segurança, ela
NÃO apaga por conta própria tokens, chaves TPM/CNG, vínculo de dispositivo,
fila cifrada, configurações pessoais ou dados de outros aplicativos. Ela
também NÃO equivale à revogação de um computador autorizado. Não exclua
arquivos de chave ou perfis para forçar o processo.

Não distribua como versão produtiva sem teste real e autorizado do Microsoft
Entra, TPM, Smecel, envio assinado, recibos e troca de computador ativo.
O instalador do aplicativo ainda não possui assinatura digital própria.
Se o Windows bloquear a execução, não desative proteções: peça orientação.

O pacote é validado por CI em Windows com dados inteiramente sintéticos.
Consulte a PR #7 do repositório coletor-frequencia-smecel para as evidências.
